# ORA · Brand System

**What this is.** The coherent set of components that make ORA operable. Not just the visual spec:
everything needed to speak, look and behave as ORA.

**Who it's for.** Anyone producing anything in ORA's name, whether that is a caption, a signage
plate or a class.

**Where it sits.** Strategy, why it works. **System**, what it is. Showcase, see it. This is the
second.

---

## The four components, in reading order

| | | |
|---|---|---|
| **01** | **Brand Story** | Where ORA came from. The founder's story, the name, and the Room, Movement and Woman as narrative. |
| **02** | **Brand Character** | How ORA speaks and behaves. Personality, tone, lexicon, naming, language policy, copy, staff conduct, refusals. |
| **03** | **Brand Identity** | How ORA looks. The visual system logic, the logo, the grid, type, colour and art direction. |
| **04** | **Brand Applications** | What ORA makes. Social, app and web, print and environment, merch, shot list. |

Story first, because rules read as arbitrary until you know what produced them. Character before
Identity, because how ORA speaks is decided before how it looks. Applications last, because it
inherits from all three.

**03 is the source of truth for anything visual.** `03 Brand Identity.html` carries the system as
built and as measured: the sixty-minute grid, the mark at 45°, three type sizes, nine colours, the
load ramp and the red curve across the five hours. Where a value written anywhere else disagrees
with that page, the page wins. `ORA_Page_Template.md`, one folder up, is how the page is built, and
it governs every page made after it.

**Applications has no document yet.** Its material is in `04 ORA - Brand Assets` as a production
guide in Macedonian.
